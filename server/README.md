# HealthScan AI reference server

Development-only reference API.

```bash
npm install
npm start
```

The Android app can use:

`http://10.0.2.2:8080`

from the Android emulator, or the HTTPS URL of your deployed server on a real phone.

Do not use this reference server for production medical data. Add authentication, authorization, encryption, database storage, audit logging, rate limiting, data retention policies, backups and applicable privacy/regulatory controls.
